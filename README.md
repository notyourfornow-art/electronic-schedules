# Электронное расписание — проект внедрения

**Назначение:** учебный комплект материалов для установки, проверки, выпуска и сопровождения условной системы «Электронное расписание».

## Возможности системы (учебная модель)
- просмотр расписания учебной группы;
- просмотр расписания преподавателя;
- публикация замен и изменений;
- разграничение прав пользователей.

> Важно: в рамках практической работы приложение представлено учебным макетом. Исполняемая информационная система и реальная база данных в репозиторий не входят.

## Ответственные
- Менеджер развёртывания — студент, выполняющий практическую работу.
- Менеджер сопровождения — назначенный специалист технической поддержки.
- Тестировщик — ответственный за smoke-тестирование.

## Структура репозитория
- `src/` — учебный макет приложения;
- `config/` — безопасные примеры конфигураций;
- `scripts/` — демонстрационные сценарии установки, развёртывания и отката;
- `docs/` — инструкции и организационные документы;
- `tests/` — чек-лист проверки;
- `releases/` — описание выпуска.

## Общий порядок внедрения
1. Проверить требования и подготовить сервер.
2. Создать резервную копию текущей версии и базы данных.
3. Подготовить конфигурацию нужной среды.
4. Выполнить установку и развёртывание.
5. Провести smoke-тест.
6. При критических ошибках выполнить откат.
7. Передать комплект документации менеджеру сопровождения.

## Версия
**1.0.0** — первая учебная версия комплекта внедрения.

## Запуск демонстрационных сценариев
В Linux/macOS из корня проекта:
```bash
bash scripts/install.sh
bash scripts/deploy.sh
bash scripts/rollback.sh
```
Сценарии выводят учебные сообщения и не устанавливают реальное приложение.

## Примечание по учебному комплекту
Перед реальным внедрением заполните параметры среды и согласуйте ответственных.
