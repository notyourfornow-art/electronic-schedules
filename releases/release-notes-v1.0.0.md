# Выпуск версии 1.0.0

**Дата выпуска:** 02.11.2026  
**Тип выпуска:** первая учебная версия комплекта внедрения.

## Добавлено
- структура репозитория проекта внедрения;
- шаблоны конфигураций development, test и production;
- инструкция по установке;
- план развёртывания и план отката;
- демонстрационные сценарии;
- smoke-test checklist;
- регламент сопровождения и акт передачи.

## Известные ограничения
- реальное приложение и база данных не поставляются;
- shell-сценарии демонстрационные и не выполняют фактическую установку;
- параметры инфраструктуры требуют уточнения для конкретного техникума.

## Обновление
1. Создать резервную копию текущей версии и БД.
2. Проверить release notes и совместимость конфигурации.
3. Развернуть файлы утверждённого выпуска.
4. Выполнить smoke-тест.
5. При критической ошибке действовать по `docs/rollback-plan.md`.
