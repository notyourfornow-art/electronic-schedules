# Инструкция по установке

## 1. Назначение
Документ описывает учебный порядок подготовки и установки условной системы «Электронное расписание».

## 2. Требования
- Windows Server или Linux;
- не менее 4 ГБ оперативной памяти;
- не менее 10 ГБ свободного места;
- доступ к локальной сети техникума;
- учётная запись администратора;
- подготовленная СУБД и доступ к резервному хранилищу.

Конкретные версии ОС, СУБД и программной платформы должны быть уточнены у поставщика реального приложения.

## 3. Подготовка
1. Согласовать окно работ с ответственными лицами.
2. Проверить доступность сервера и свободное место.
3. Зафиксировать текущую версию системы.
4. Создать резервную копию файлов приложения и базы данных.
5. Проверить возможность восстановления резервной копии.
6. Выбрать шаблон конфигурации из `config/` и заполнить его реальными параметрами на сервере. Секреты не помещать в Git.

## 4. Установка
1. Получить утверждённый дистрибутив приложения.
2. Проверить целостность и источник дистрибутива.
3. Подготовить каталог установки и права доступа.
4. Создать или проверить базу данных.
5. Применить настройки выбранной среды.
6. Установить файлы приложения по инструкции поставщика.
7. Запустить службу приложения.
8. Проверить журналы запуска и доступность сервиса.

## 5. Контроль результата
- главная страница доступна;
- авторизация работает;
- расписание отображается;
- тестовые изменения сохраняются;
- критические ошибки в журналах отсутствуют.

**Ожидаемый результат:** система доступна, базовые функции проверены, результаты зафиксированы. В данном репозитории приложение условное; шаги установки являются регламентом, а не фактической установкой ПО.
